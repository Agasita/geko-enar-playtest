1. 共通ルール

1-1 ブロックの種類と「動かせるか」

種類編集で動かせる備考
普通のブロック（茶・赤・青・緑）○色に性質がある（茶＝普通／赤＝熱い・触れるとダメージ／青＝氷で滑る／緑＝バネで跳ねる）
ひび割れ（旧・黄色）○乗ると約0.5秒で崩れる。壊れやすい
ガラス（色なし）○「いろコピー」で色が付けられる唯一のブロック。色が付いたものは「色つきガラス」
磁石（M）○「いろコピー」のコピー元にはできない。フィルターの影響を受けない
保護ブロック（鍵つき）×「まもりをはずす」で解除すれば動かせる。フィルターでも消えない。並べ替えの区切りになる
鋼（はがね）×常に壁。並べ替えの区切りになる。範囲外もここで止まる
トゲ×触れると即ミス。編集の対象外
リフト×編集では動かせない。通り道（レール）にはブロックを置けない。ガラス色のリフトは色付けできる
ドア・判定セル・スイッチ×ドア・判定セルは編集の対象外（ドアの位置には、ブロックを置けない）
にせブロック（敵）×ブロックではない。編集もコピーも効かない

1-2 コスト（エナジー）

  • ステージごとに「使える道具」と「コスト上限（energy）」が決まっている。ふつうは回復しない。実験シート（LAB）だけは自動回復あり（上限100）。
  • エナジーの玉をとると、コストが15回復する（上限まで）。
  • 確定した編集ごとに、その道具のコストが引かれる。元に戻す／やり直すは何度でもでき、戻すとコストも全額戻る。
  • 練習モードでは、コストは無限。
  • 救済：同じステージで3回失敗すると、コスト上限が1.5倍（切り上げ）になる。クリアすると元に戻る。
  • コストを使い切って最小コストを下回ると「もう編集できません」と出る。

1-3 編集のしくみ

  • 「なおす」に入ると時間が止まる。敵・リフト・判定セルとドアも止まる。編集を終えると動き出し、判定セルとドアの結果もそのときに分かる。
  • 範囲を選ぶ道具は、ドラッグで矩形を選ぶ。確定の前に、できるかどうか・コスト・変わる場所が先に計算され、できないときは理由が出る（失敗してもコストは減らない）。
  • どの道具も、何もないところにブロックは生まれない。あるブロックを動かす・並べる・色を変える・保護する・見えなくする、だけ。（敵の「オートフィル」だけは、ブロックを作る）
  • エナー・敵・リフトの通り道・ドアのあるマスには、ブロックを動かして重ねられない（失敗理由：エナーやリフトの通り道が邪魔です）。
  • 改ページプレビュー（ワールド14）では、見える範囲の外は編集できない。ズーム中も編集できない。

1-4 エナーのダメージと踏みつけ

  • ライフは3。敵や赤いブロックに触れると1ダメージ。直後の約1.3秒は無敵で、後ろに弾き飛ばされる。
  • トゲ・穴・ライフ0・リフトにはさまれる、はミス（ステージを最初から）。
  • 踏みつけ：落ちている最中（下向きの速さが60以上）に、敵の上から重なると、敵に1ダメージ。エナーは上に跳ね返る（速度-240）。タレット・#DIV/0!・循環参照・にせブロックは、踏めない。
  • 敵ごとの体力（hp）に応じて、踏む回数が決まる（下の表）。

3-2 共通のふるまい

  • 歩く敵（てくてく・かたいこうら・#DIV/0!・しろい文字・塗りつぶし）は、重力で落ち、ふちや壁で折り返す（しろい文字は止まる）。
  • 敵が出現してから、エナーが約150px以内に近づくと、「てき図鑑」に載る（しろい文字は正体を現したとき／にせブロックは目が開いたとき）。
  • 非表示にされた行・列にいる敵は、そこにいない扱いになる。
  • 編集中は、すべての敵が止まる（敵の攻撃・敵の編集的ふるまいも止まる）。
  • 敵の「ブロックを変えるもの」（条件つき書式・並べ替え・オートフィル・塗りつぶし）は、エナーの編集と同じ盤面を書きかえる。保護ブロックには作用しない。人・敵のいるマスや、リフトの通り道・ドアには、ブロックを作らない。

並べ替え （type: shuffler）

動き最初2.4秒、その後4.2秒ごとに、範囲内のブロックを片方向に寄せる（寄せる向きは、そのたび反対になる）。寄せる1秒前から光る。鋼・磁石・ひび割れ・保護で区切られ、人や敵のいる所は動かさない。

ステージ作成での指定ranges／axis（x=横に、y=縦に）／dir（最初の向き）

3-4 気づいた点（仕様とコードのずれ）

  • タレット（たまうち）は実装済みだが、どのステージでも使っていない。
  • コードには、ダッシュ・攻撃・ステージ作成用の古い計画関数（移動・入れ替え・消す・色置き換え・行や列の非表示／挿入／削除）が残っている。現在の「なおす」の道具（8種）からは使えない。
  • 「かたいこうら」の盾は、古い「攻撃」入力に対するもの。現在のエナーには攻撃入力がないので、実際には踏みつけ2回で倒す。
  • 磁石は「動かせるブロック」として扱われる（かたち・ならべかえで動く）。意図どおりか未確認。
