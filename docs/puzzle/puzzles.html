1. 編集機能ごとの発想

8つの道具を、「何を動かす／変えるか」「どこで止まるか」「いつ使うか」から考えた単体のアイデア。

いろコピー（ガラスにだけ色がつく）

  • 緑の踏切台：床のガラスを緑にして、高い棚へ跳ねる。広く塗ると手前でも跳ねてしまう（範囲選びが難しさ）
  • ひとふで2か所：離れた2枚のガラスを1つの矩形に入れて、1回で2つの踏切にする（途中の普通ブロックは変わらない）
  • 氷の滑走台：ガラスを青にして、勢いをつける／止まれなくする
  • 熱い壁・熱い床：ガラスを赤にして、通せんぼや罠にする（塗る前は安全）
  • もろい足場：ガラスを「ひび割れ色」にして、乗ると崩れる足場に。一度きりの橋や、敵を落とす罠
  • 判定セルの鍵：色判定のセルがガラスなら、色を塗った瞬間に扉が開く
  • ガラスのリフト：リフトにも色がつく。上がった所で緑にして、動くバネに
  • 見本の位置：見本は「どのブロックを見本にするか」で色が決まる。見本が遠いと、取りに行く寄り道が必要

かたち（反転・回転）

  • 階段を逆向きに：下る階段を、左右反転して登る階段にする
  • 天井の足場を床へ：上下反転で、上に余った足場を下へ降ろす
  • 縦棒を橋に：正方形で選んで90°回すと、縦の棒が横の橋になる（長方形では回せない）
  • L字を同時に回す：正方形の対角にあるL字を回して、入口の踏み段と出口の踊り場にする
  • 鏡の対称：足場と欠けが左右対称になる範囲を選ぶ（端が1マスずれると鋼の柱に当たって失敗）
  • 色や性質ごと運ぶ：緑のブロックを、判定セルの上へ動かして色鍵にする（反転で鍵を渡す）
  • 敵の足もとの見本を入れ替え：オートフィルは足もとの色をコピーする。反転で、作る色を変える
  • 通り道のよけ方：エナー・敵・リフトのレールにはブロックを動かせないので、選ぶ範囲と先を読む

ならべかえ（寄せる）

  • 橋にする：穴の手前のブロックを、穴の向こうの端まで寄せる（1段上の高さに橋ができる）
  • 階段にする：縦に寄せると、列ごとの個数がそのまま段差になる
  • 仕切りを読む：鋼・保護ブロック・リフトのレール・敵・エナー・扉が、寄せを止める。エナーが立つ場所で寄せ先が変わる
  • 右にも左にも使う：左の材は柱際に、右の材は端に集まる（1回の寄せで2か所の橋）
  • 不要なブロックを追い出す：範囲の外へ運んで、オートフィルの在庫を空にする
  • 鍵を抜いて長く寄せる：保護を外してから寄せると、仕切りが橋材になる
  • 持ち上げる：低い所に生えた橋を、上寄せで出口の高さへ
  • 磁石も寄る：磁石は動かせるブロックなので、寄せた先で敵の寄せの仕切りになる

フィルター（色で残す）

  • 壁抜け：通りたい床の色を残すと、ほかの色の壁が消える（赤壁は茶色を残す）
  • 危険を消す：赤い床や赤い敵の足場を消して、安全にする
  • 足場も消える：残さない色の足場も消える。消したくない足場は「まもる」で残す
  • 2回切り替え：途中で残す色を替えて、前半と後半で違う壁を抜ける
  • 無料で戻る：「外す」はコスト0。戻った足場で、エナジー0でも渡れる
  • 判定が変わる：「あるなし」判定は、フィルターで消えると「ない」になる。扉が閉まる→外すと開く
  • リフトの色：色が違うリフトは通り抜けられる（のれなくなる）。のりたいリフトの色を残す
  • 敵の足場を消す：歩く敵の床の色を消すと、敵が落ちる（ふわふわ以外）

シートをまもる／まもりをはずす

  • 足場を固定：敵の「書式」や「寄せ」から、残したい足場を守る
  • 仕切りを作る：保護したブロックは、寄せの区切りになる。上寄せで「中段の足場」を残せる
  • フィルターから守る：保護ブロックはフィルターで消えない。青い着地点だけ残す
  • 塗り屋から守る：保護したガラスは、塗りつぶしの敵が塗れない（着地点の確保）
  • 色を固定：条件つき書式の敵が赤にした瞬間に保護すると、赤のまま残る（色判定の鍵に）
  • 先に外す：保護を外してから「かたち」「ならべかえ」を使う（コスト6が上乗せ）

印刷範囲の設定・ズーム（改ページプレビュー）

  • 遠くの編集：見える所だけ編集できる。先に細長い範囲で「見える所」を伸ばしてから、動かす
  • 枠の連鎖：枠は、いま見えている範囲に重ねて選ぶ。見えた所に重ねて、さらに伸ばせる（40マスまで・3か所まで）
  • 枠を残しておく：スタートで、あとで使う場所を残す。進んだあとに、遠くを編集する
  • ズーム下見：5秒間広く見える。敵の動き（循環参照など）を観察してから進む
  • 一列だけ切り取る：高さ1マスの帯なら、離れた2点も1つの枠に入る

2. ブロックと仕掛けの使い方

ブロックの色・種類と、仕掛け（リフト・扉・判定セル）が持つ性質から考えたアイデア。

色の性質（ブロック・床・壁）

  • 茶：ふつう。壁にも床にも。フィルターで「残す色」にしやすい
  • 赤：熱い。触れるとダメージ。壁・床の罠、にせブロックを押す道具
  • 青（氷）：滑る。着地の誤差、勢いの保持。橋が氷だと、止まれない
  • 緑（バネ）：約5.5マス跳ねる。棚への近道、高い穴の脱出
  • ひび割れ：乗ると約0.5秒で崩れる。一度きりの橋、落とす罠、足場が消える仕掛け
  • ガラス：色なし。色を付けられるのはこれだけ。塗りつぶしの敵の標的
  • 磁石：フィルターに消されない、寄せの仕切り（敵の寄せでも）

壁と床の工夫

  • 1マスの段差：赤を「飛び越える」だけの罠
  • ひとつ高い床：1マス低い所から跳び乗れる。2マスの壁は跳べる、3マスは跳べない（約2.6マス）
  • トゲの天井：バネの高さを制限する（広く塗ると、手前でトゲに当たる）
  • 鋼のくぼみ：エナーが立つと、寄せの仕切りになる
  • 床より1マス高い橋：床から跳び乗って、そのまま渡れる高さ

リフト

  • 周期：決まった道を往復。乗り移るタイミングを読む
  • ガラスのリフト：色を付けると、動く踏切台や動く氷に
  • レールは侵入禁止：ブロックを置けない（寄せの仕切り・かたちの失敗理由）
  • 判定で動かす：判定セルがONの間だけ動くリフト
  • はさまれる：壁との間で、逃げ場があってもミス

判定セル・扉・スイッチ

  • 存在判定：実体のあるブロック（または立ったエナー）がいるとON。フィルターで消える
  • 空き判定：何もないとON。エナーが立つとOFF
  • 色判定：指定した色のブロックがあるとON。ガラスを塗る、緑を運ぶ、敵が作る・塗る
  • 複数の判定：同じ番号の判定がすべてONで扉が開く（AND）
  • 編集中は止まる：編集を終えてから結果が出る。試行錯誤ができない設計
  • 二重扉：色判定の扉と、存在判定の扉を直列に。フィルターを使うタイミングが問われる

3. 敵キャラの使い道

敵を「障害」だけでなく、「足場」「時計」「道具」「仕掛けの入力」として使う発想。

歩く敵

  • てくてく：踏める・1回で倒れる。倒すまでの時間を使った「足止め」。ふちで折り返す
  • かたいこうら：2回踏む。踏み返りを2回使う連続ジャンプの足場
  • #DIV/0!：踏めない・倒せない。上の棚でやり過ごす「見張り」
  • しろい文字：近づくと現れて追ってくる。誘い出して穴に落とす、切れ目を跳び戻る
  • 塗りつぶし：ガラスを塗る。倒すと元に戻る。「塗らせて通す」「倒して戻す」「保護で守る」

空中・固定の敵

  • ふわふわ：空中で往復。踏み返りで谷を渡る足場。敵が戻る周期に合わせる
  • たまうち：弾の道から外れる。光ったら動く、撃ったあとに切り返す（まだステージでは未使用）
  • 循環参照：長方形の道を回る。交差点を通る順番・周期を読む。ズームで下見
  • にせブロック：壁のふりで通せんぼ。赤い隣で逃げる。見破る・押しのける

盤面を書きかえる敵

  • オートフィル：足もとの高さに、ブロックを増やす。「待つ」と橋になる。「止める」（踏む）と数を調整できる。cap・max・向き・色の設定
  • 条件つき書式：範囲の色を順に変える。予告の点滅で安全な色を待つ。緑になった瞬間に「まもる」で固定
  • 並べ替え（敵）：範囲を交互に左右へ寄せる。重なる位置で待つと渡れる「桟橋」。ひび床や磁石で仕切りが変わる

敵の力を借りる発想

  • 橋職人：オートフィル／並べ替えを「待つ」「止める」「向きを変える」で道具にする
  • 鍵職人：敵が作った（塗った）ブロックを、判定セルの鍵にする
  • 押し出し：赤いブロックを、にせブロックの隣に置いて動かす
  • 時間稼ぎ：歩く敵や、周期のある敵が、条件を満たすまでの時計になる
  • 敵が邪魔をする編集：敵の書式・寄せを、保護で止める

4. 組み合わせて難しくする

単体のアイデアを、「順序」「色」「時間」「空間（視界）」「資源（コスト）」の軸で掛け合わせる。★は難しさの目安。

順序（先にやらないと詰む）

  • 守ってから消す（★★）：保護 → フィルター。逆だと足場が消える
  • 塗ってから通す（★★）：色コピー → フィルター。判定を満たしてから壁を消す
  • 外す、そして戻す（★★★）：フィルター → 外す（コスト0）。扉の存在判定を戻して開ける
  • 鍵を抜いてから寄せる（★★）：まもりをはずす → ならべかえ
  • 先に枠、あとで編集（★★★★）：印刷範囲 → 歩く → 遠隔でかたち
  • 押しのける（★★★）：赤を落とす（↓よせ）→ にせブロックが逃げる → くぼみへ

色（性質を設計する）

  • 3色の足場（★★★）：青（氷）の橋、緑（バネ）の踏切、赤（熱）の罠が同じ道に
  • 色鍵と壁の色（★★★）：判定は緑、壁は赤。残す色は緑。工場が緑を作る
  • 氷の橋（★★★）：寄せて作った橋が氷。滑りを読んで、次の穴を跳ぶ
  • ガラスの賢い使い方（★★★）：1枚だけ守って、ほかは塗らせる／自分で緑にする

時間（待つ・合わせる）

  • 桟橋の重なり（★★★）：敵の寄せの周期に合わせて、重なる位置で待つ
  • 色の波（★★★★）：条件つき書式の予告を見て、安全な色の間に渡る／緑で固定
  • 工場を待つ（★★★）：オートフィルが橋を作るまで待ち、できたら上に持ち上げる
  • 塗り屋を生かす／倒す（★★★）：塗らせて通る、通ったら踏んで鍵を戻す
  • 周期を観察（★★★★）：ズームで循環参照の向きを確認して、交差点を抜ける

空間（視界・高さ）

  • 細い窓（★★★★）：細長い印刷範囲で、離れた2点を1回の反転に入れる
  • 枠の連鎖（★★★★）：重ねて広げた枠で、長い橋を一度に寄せる
  • 遠隔の鍵（★★★★★）：見えなくなる遠くの範囲を、先に残しておく
  • 高さの設計（★★★）：生成する高さと、使う高さを分ける（寄せで持ち上げ）

資源（コスト）

  • ぎりぎりの予算（★★★）：上限が編集の合計と同じ。ムダな試行ができない
  • 戻して選び直す（★★）：失敗しても、元に戻せばコストが全額返る
  • 2つの解（★★★）：安いが難しい手順と、高いが確実な手順（別解）
  • 無料のフィルター外し（★★★）：コスト0の操作を使い切り戦略に

5. ステージ作りの原則と、これから

検証ボットで解けることを確かめながら作る中で、気づいたこと。

作るときの原則

  • 編集の結果は「寄せる前に」予想できる：選んだ範囲と、仕切りが目で見える盤面にする
  • 失敗しても戻れる：「元に戻す」でコストが返る。落ちたらやり直せる、が気楽さの前提
  • ジャンプは約2.6マス・約3.6マス幅：1つの穴は3マス以内。氷・バネ・ふわりを使うときは、長めに見積もる
  • 床より1マス高い橋：寄せで作る橋は、床の1つ上（行9）が作りやすい
  • 敵の周期を重ねすぎない：待ち時間が長すぎると、遊びが止まる
  • 解法は1つに絞らなくてよい：別解を残すと、やりこみの余地になる

検証で分かったこと

  • 前回（外部資料の60案）をボットで確かめると、60面中46面が解け、14面が解けなかった（U05, U14, U23, U25, U35, U36, U39, U40, U49, U50, U51, U53, U56, U60）。編集は成立しても、歩きの幅・高さが足りない面があった
  • 踏みつけの跳ね返りは小さい（約1.6マス）。踏み返りで高い棚へ上がる面は、成立しにくい
  • 改ページプレビューの面は、「枠を重ねる位置」が決まっているので、スタート位置が大切
  • オートフィルは、敵の足もとのすぐ隣から穴が始まる必要がある（間に鋼の床があると生成しない）

これから試せること

  • 磁石を主役に：寄せの仕切りとして使う面（今回は未使用）
  • たまうちを使う面：弾を誘う面（未使用）
  • かたいこうらの連続踏み
  • 判定セルのAND：複数の判定を同時に満たす
  • 敵×編集の競争：敵の寄せと、自分の寄せのタイミング争い
  • スコアアタック：コスト・時間・かけらのランク

検証のしかたと、ステージ一覧

人が遊ぶ前に、ステージが「ほんとうに解ける」ことを機械で確かめました。ゲームの本物の物理（歩き・ジャンプ・ふわり・ダメージ）を使い、解法の編集を適当なタイミングで挟みながら、左右・ジャンプの操作を探索（A*）して、旗までたどり着けるかを調べるボットです（scripts/stage_bot.js）。ダメージを受けた道は捨てるので、「ノーミスで」クリアできることも確認できています。

ねらい

同じ道具を、向きを変えて二度使う入門面。横寄せで橋、縦寄せで階段を作る。

解法

  1. 手前の4つのブロックを囲んで「→よせ」：穴の上に橋ができる（かけら1つ目は橋の上）
  2. ばらばらに浮いた3列を囲んで「よせ↓」：1・2・3段の階段になる
