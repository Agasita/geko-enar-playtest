# 画像生成AIへの依頼仕様（第2弾：アイコン・タイトル・ボタン・UIの絵）

第1弾（主人公とブロック。`docs/GPT_SPEC_PHASE1.md`）と同じ方式です。
**大きめの「ドット絵風」の絵を作ってもらい、あとで Claude Code が、ゲームの大きさ（32px基準）に縮小・整形します。**
絵柄・色・禁止事項は、第1弾の「1. 共通のデザイン方針」（英語のプロンプトと32色のパレット）を、**毎回そのまま先頭に貼ってください**。この資料は、それに足す「大きさと中身」だけを書いています。

参考：全体の一覧は `docs/ASSET_LIST.md`（このページの対象は、その F・G・J の一部）。

## 0. まず、守ってほしい共通ルール

| 項目 | 内容 |
|---|---|
| 背景 | 全面ベタ塗りの蛍光ピンク `#FF00FF`（透明にしない）。絵の中には使わない。あとでこちらで透明にする |
| 文字 | **絵の中に、文字を入れない**（日本語は崩れやすい）。ボタンやロゴの文字は、ゲームが上に重ねて描く |
| 禁止 | ぼかし、グラデーション、光のにじみ、地面に落ちる影、ノイズ、紙の質感、枠線、透かし、マス目の線 |
| 輪郭 | 濃い紫 `#2E2A44`（真っ黒は使わない） |
| 光 | 左上から。影は右下 |
| 角ばった絵 | 「ドットが見える」絵。1ドットより細かい模様は、描かない |
| 画像の大きさ | AIが指定どおりに出せないときは、**近い大きさで構いません**（こちらで整えます）。ただし、縦横の比は守ってください |
| 絵柄の続き | 最初に、`docs/gpt_refs/` の参考画像2枚を添付し、「この絵柄と色を続けてください」と言う |
| 進め方 | 1回に1枚。直してほしい点を言葉で伝える。うまくいかないときは、**単色の背景のまま**でよい |

> 「1ドット」の大きさは、絵によって違います（下の各項目に書きました）。**その大きさの正方形のかたまりで描く**よう、プロンプトに必ず書いてください。

## 0.5 主人公「エナー」の設定（どの絵でも、これを守る）

**エナーは、シマエナガ（雪の妖精と呼ばれる、小さな白い鳥）の形をした、ロボットです。**

| 部分 | 設定 |
|---|---|
| 体 | まん丸でふわふわに見える、真っ白な体（`#FFFFFF`、影は薄灰 `#D9D9D9`）。首はほとんどなく、頭と体が、ひと続きの丸い形。ロボットらしさは、**つなぎ目の線を少し**だけ（金属の缶のようにしない。ふわふわの形を保つ） |
| 顔 | 目は、**小さな黒い点**（`#262626`）。くちばしは、**とても小さい**オレンジ `#ED7D31`。ほほに、ほんのり淡い桃色（`#EDA198`）を、1〜2ドット |
| 羽（つばさ） | **キーボード**。体の横に付いた翼が、小さな**キー（四角いキートップ）が並んだ形**。キーは、淡い青 `#9DC3E6` と青 `#5B9BD5`（小さいサイズでは、キーの数を減らし、青い面として描く） |
| 尾（お） | **USBケーブル**。シマエナガの特徴の、**長い尾**がケーブルになっている。体の後ろに、細く長くのびて、**先に、小さなUSBプラグ**（四角い金属の端子。灰色 `#B7B4C4` と濃い灰 `#59617D`）が付いている。ケーブルは、濃紫 `#2E2A44` か灰色 |
| 大きさの比 | 体：丸く大きく。くちばし・目：小さく。尾：体と同じくらいの長さ |
| 向き | **右向き**が基本 |
| 表情 | 子ども向けの絵本のように、やさしい。こわい・無表情・メカメカしい感じは避ける |
| 避けること | 人の手足、口の歯、赤く光る目、大きな機械の部品、リアルなキーボード（文字入りのキー） |

> 迷ったら、「ふわふわの白い丸いシマエナガに、青いキーボードの翼と、長いUSBケーブルの尾が付いた、かわいいロボット」と伝える。

**英語（プロンプトに足す）**

```
The main character "Enar" is a cute robot shaped like a Japanese long-tailed tit (shima-enaga): a tiny, perfectly round, fluffy white bird with almost no neck, a very small orange beak, a tiny black dot eye and faint pink cheeks.
Its wings are small KEYBOARDS (rows of little blue keycaps, no letters on the keys).
Its long tail is a thin USB CABLE ending in a small USB plug (gray metal).
Keep it soft, friendly and picture-book-like; it must NOT look like a scary or heavy machine. Face right.
```

## 1. ホーム画面のアイコン（J1）

| 項目 | 内容 |
|---|---|
| 大きさ | **1024×1024**、正方形、1枚 |
| 1ドット | **8×8px**（128×128ドットの絵を、8倍に拡大した見た目） |
| 背景 | 透明にしない。**四隅まで、絵で塗りつぶす**（角は丸めない。端末側が丸める・切り抜く） |
| 大事な絵の範囲 | **中央の約6割（620×620）の中**。Androidが円形に切り抜くため |
| 内容 | エナー（上の「エナーの設定」。シマエナガ型のロボット）の**丸い体と顔、キーボードの翼**を大きく、右向きかやや正面。USBケーブルの尾が、画面の端に、少し見える。背景は、Excelの緑 `#217346` のベタ塗りに、うすい格子（セルの罫線）。右下に、金色 `#F5C842` の「かけら」を1つ |
| 注意 | 小さく（32px）見ても分かるように、**形を1つに絞り、細かい飾りは付けない**。文字は入れない |

**納品後の作業（こちらで行う）**：180（iPhone）、192・512（Android）、32・16（タブ）に縮小。余白を足した「マスカブル版」も作る。

## 2. タイトル画面

### 2-1. ロゴ（G1）

| 項目 | 内容 |
|---|---|
| 大きさ | **1440×480**（比 3:1）。ゲームでの大きさは 480×160 |
| 1ドット | **3×3px** |
| 背景 | ピンク（あとで透明にする） |
| 内容 | 「エナーとふしぎのシート」のロゴの**飾り**。表計算のセルが何枚か重なって、**文字を載せる、空の看板（銘板）**になっている。上に、エナー（上の設定どおり）が、ちょこんと乗っていて、USBケーブルの尾が、看板の横に、たれている。**文字は、描かない** |
| 文字 | ゲームが、フォントで重ねる（「エナーと**ふしぎ**のシート」。「ふしぎ」だけ、金色 `#C99A1E`） |

### 2-2. タイトルの絵（G2）

| 項目 | 内容 |
|---|---|
| 大きさ | **1728×1080**（比 16:10）。ゲームでの大きさは 576×360 |
| 1ドット | **3×3px** |
| 背景 | 透明にしない（絵が全面） |
| 内容 | 朝の草原に、エナー（シマエナガ型のロボット。右向き、中央やや左。尾のUSBケーブルが、長く後ろにのびる）。遠くに、**こわれた表計算のシート**（セルがずれ、`#REF!` のようなエラーのかけらがちらばる）が見える。空は、少し暑い・寒いがまざった、不思議な空（左半分は暖色、右半分は寒色）。ブロックの色（茶・赤・青・緑・黄）を、小さな足場として散らす |
| 空けておく場所 | **中央〜下の約4割は、ボタンが載る**ので、絵を描きこみすぎない（ゆるやかな草原や空） |
| 大事な絵の範囲 | 横長のスマホでは、**左右が1割ずつ切れる**ことがある。エナーとシートは、**横の中央8割の中**に |
| 禁止 | 文字、ロゴ、ボタン |

### 2-3. タイトルのボタン（F8）

タイトルのボタンは「遊ぶ」「あそびかた」「ブロック図鑑」「オープニング」「⚙ せってい」の5つです。文字は、ゲームが重ねます。

**1枚のシート**（1536×1024、ピンクの背景）に、次を描きます。

| 位置 | 内容 |
|---|---|
| 左の列（4つ） | **大ボタン**：640×160（ゲームでは 160×40）。「遊ぶ」用。上から、①ふつう ②押している間 ③押せない（灰色） ④選んでいる（光っている） |
| 右の列（4つ） | **小ボタン**：512×128（ゲームでは 128×32）。そのほかのボタン用。同じ4つの状態 |
| 1ドット | **4×4px** |

- 1つの絵は、列の中で、縦横ともに中央に置く。ほかのボタンと重ならない。
- **左右の端 48px（12ドット）は「端」の飾り、真ん中は、ただの平らな面**にしてください。画面の幅に合わせて、真ん中を伸ばして使います（9分割）。真ん中に、模様や飾りを入れない。
- 見た目：白い縁取り（外側）→ 太い濃紫の線 → 淡い塗り。角は丸い。
  - 大ボタンの塗り：Excelの緑 `#217346`（文字が白で載る）
  - 小ボタンの塗り：淡い灰 `#D9D9D9`（文字が濃い色で載る）
  - 「押している間」は、塗りを少し暗くし、影を消して、1ドット下げる。
  - 「押せない」は、灰色 `#B7B4C4`。
  - 「選んでいる」は、金色 `#F5C842` の縁が光る。

## 3. 画面のUI（アイコン類）

道具と操作のアイコンです。ゲームの中では、**16〜24px**の小さな大きさで見えます。
形が分かりやすいよう、**線を太く、2〜3色、細かい飾りなし**にしてください。

**シートの決まり（第1弾と同じ）**：1536×1024、**6列×4行**、1マス256px、絵は中央の**224×224**（1ドット＝7×7px。32×32ドットの絵を7倍にした見た目）、背景はピンク、マス目の線は描かない。

## 5. こちら（Claude Code）が行う後処理

- 縮小（面で平均）→ 共有32色のパレットに寄せる → 輪郭をそろえる → ピンクを透明にする → 切り出し・名前づけ
- ボタンの9分割の切り出し、アイコンのマスカブル版、各サイズへの縮小
- ゲームへの組み込み（今のCSSのボタンを、画像に置き換える。**元の見た目は、切り替えで戻せるように残す**）

## 6. 受け入れの目安

- 指定した比と、ほぼ同じ大きさ。
- 角ばっていて、ぼけていない。ぼかしや光のにじみがない。
- アイコンを、**16pxに縮めても、何か分かる**。
- 絵の中に、文字・ロゴが入っていない。
- ボタンの真ん中が、平らで、横に伸ばせる。
- 色の意味（茶・赤・青・緑・黄・ガラス・鋼）を、変えていない。
