# 画像生成AIへの依頼書：ゲーム「エナーとふしぎのシート」のグラフィック

この文書は、画像生成AI（ChatGPTなど）に、そのまま渡すためのものです。
1回に1枚ずつ、「このうち、**〇番**を作ってください」と頼んでください。

## 1. ゲームについて

- ブラウザで遊ぶ、パズルアクションゲームです。対象は子どもから大人まで。語り口は、**絵本のようにやさしく、あたたかい**。
- 世界は、**表計算ソフト（Excel）の中**です。足場のブロックは、色のついたセル。画面には、Excelのような、リボンや、行・列の見出しが出ます。
- 雰囲気は、「**表計算のように、きっちりしていて、絵本のように、あたたかい**」。こわい・不気味・攻撃的は、避けます。

## 2. 主人公「エナー」

**シマエナガ（雪の妖精と呼ばれる、小さな白い鳥）の形をした、ロボット**です。

- 体：まん丸でふわふわの、真っ白（`#FFFFFF`、影は薄灰 `#D9D9D9`）。首はほとんどなく、頭と体がひと続きの丸い形。
- 顔：目は小さな黒い点。くちばしは、とても小さいオレンジ `#ED7D31`。ほほに、淡い桃色 `#EDA198` を少し。
- **羽は、キーボード**：小さな青いキー（四角いキートップ）が並んだ翼。キーは `#9DC3E6` と `#5B9BD5`。キーに、文字は描かない。
- **尾は、USBケーブル**：シマエナガの長い尾が、細いケーブルになっていて、先に小さなUSBプラグ（灰色 `#B7B4C4`、濃い灰 `#59617D`）。体と同じくらいの長さ。
- 向き：**右向き**。表情：やさしい。
- 避けること：人の手足、歯、赤く光る目、大きな機械の部品、重たそうな金属の缶のような見た目。

## 3. 絵の決まり（全部に共通）

最も大事なのは、**角ばった、にじみのない、ドット絵のような絵**であることです。あとで、こちらが、小さく縮めて使います。

- すべての「ドット」は、**正方形のかたまり**。その大きさは、各項目に書いてあります（例：7×7px）。それより細かい模様・線は、描かない。
- ベタ塗りの色だけ。**ぼかし、グラデーション、光のにじみ、地面に落ちる影、アンチエイリアス、ノイズ、質感、枠線、透かし**は、すべて禁止。
- 輪郭は、濃い紫 `#2E2A44`。**真っ黒は使わない**。影は、同じ色の暗い色。光は左上から、影は右下。
- **背景は、全面ベタ塗りの蛍光ピンク `#FF00FF`**（透明にしない）。絵の中には、ピンクを使わない。※背景まで絵になる、タイトルの絵・アイコンだけは別（各項目を見る）。
- **絵の中に、文字は入れない**（日本語は崩れるため）。文字は、ゲームが重ねます。
- 使う色は、次の32色だけ：
  `#2E2A44 #FFFFFF #FFF8F0 #D9D9D9 #EBD9C4 #C9A15E #985E46 #704651 #E8563F #A03E4B #ED7D31 #FFD966 #F5C842 #6FD6E8 #397FA3 #5B9BD5 #9DC3E6 #58B368 #217346 #93C781 #4472C4 #59617D #8892AA #B7B4C4 #86568B #BD81A1 #FFD9B0 #727243 #9A9770 #EDA198 #70AD47 #45506B`
- 色の意味（ブロックの色は、変えない）：茶＝ふつうの足場 `#C9A15E`、赤＝熱い `#E8563F`、青＝氷 `#6FD6E8`、緑＝バネ `#58B368`、黄＝もろい `#F5C842`、無色＝ガラス、灰＝鋼。色だけでなく、形（亀裂・つや・コイル・割れ目・リベット）でも見分けられるように。
- 画像の大きさを、指定どおりに出せないときは、**縦横の比を守った近い大きさ**で構いません。

> 毎回、最初に、この「3. 絵の決まり」と、「2. 主人公エナー」を、そのまま貼ってから、依頼してください。参考画像（添付）があれば、「この絵柄と色を続けてください」と伝えます。

## 4. お願いするもの

### ① ホーム画面のアイコン
- **1024×1024**、正方形、1枚。ドットの大きさ：8×8px。
- **背景も、絵で塗りつぶす**（角まで。角は丸めない）。大事な絵は、**中央の約6割**に収める。
- 内容：エナーの、丸い体と顔、キーボードの翼を大きく（右向きかやや正面）。尾のUSBケーブルが、端に少し見える。背景は、Excelの緑 `#217346` に、うすい格子（セルの罫線）。右下に、金色 `#F5C842` の「かけら」を1つ。
- 小さく見ても分かるよう、**形を1つに絞り、飾りは少なく**。

### ② タイトルのロゴの飾り
- **1440×480**（3:1）。ドット：3×3px。背景は、ピンク。
- 表計算のセルが何枚か重なった、**文字を載せる、空の看板**。上に、エナーがちょこんと乗り、USBの尾が、看板の横にたれる。**文字は描かない**。

### ③ タイトルの絵
- **1728×1080**（16:10）。ドット：3×3px。背景も、絵にする。
- 朝の草原に、エナー（右向き、中央やや左、尾のUSBケーブルが後ろに長くのびる）。遠くに、**こわれた表計算のシート**（セルがずれ、`#REF!` のようなエラーのかけらがちらばる）。空は、暑い・寒いがまざった不思議な空（左が暖色、右が寒色）。ブロックの色の、小さな足場を散らす。
- **中央〜下の約4割は、ボタンが載る**ので、描きこまない。横の左右1割は、切れることがある。文字・ロゴ・ボタンは描かない。

### ④ ボタン（1枚のシート）
- **1536×1024**、背景はピンク。ドット：4×4px。
- **左の列**に、大ボタン（**640×160**）を4つ：①ふつう ②押している間 ③押せない（灰色 `#B7B4C4`）④選んでいる（金色 `#F5C842` の縁が光る）。塗りは、Excelの緑 `#217346`。
- **右の列**に、小ボタン（**512×128**）を、同じ4つの状態で。塗りは、淡い灰 `#D9D9D9`。
- 見た目：白い縁取り → 太い濃紫の線 → 淡い塗り。角は丸い。「押している間」は、塗りを少し暗くし、影を消す。
- **左右の端 48px は飾り、真ん中は、ただの平らな面**（横に伸ばして使うため。模様を入れない）。文字は描かない。

### ⑤ 道具と操作のアイコン（24個、1枚のシート）
- **1536×1024**、**6列×4行**、1マス256px。絵は、各マスの中央の**224×224**。ドット：7×7px。背景はピンク。マス目の線は描かない。
- 画面では、16〜24pxの小さな大きさで見えるので、**線を太く、2〜3色、飾りなし**で。同じ線の太さ・色づかいにそろえる。
- 左上から右へ、次の行へ：
  1 いろコピー（スポイトと、色のついたセル）／2 かたち（四角が左右に反転する矢印）／3 ならべかえ（大小のセルが1方向に寄る矢印）／4 フィルター（じょうご）／5 シートをまもる（盾か、錠つきのセル）／6 まもりをはずす（ひらいた錠）／7 印刷範囲の設定（青い枠で囲んだ範囲）／8 小窓（大きな枠の隅に、小さな窓）／9 上下分割（四角を、横線で上下に割る）／10 左右分割（四角を、縦線で左右に割る）／11 ズーム（虫めがね）／12 なおす・時間停止（時計）／13 終わる（旗）／14 元に戻す（左に曲がる矢印）／15 やり直す（右に曲がる矢印）／16 移動（開いた手）／17 書き込み（鉛筆）／18 音ON（スピーカーと音の波）／19 音OFF（スピーカーに斜めの線）／20 せつめい（丸の中の「？」の形）／21 せってい（歯車）／22 消しゴム／23 BGM（音符）／24 ステージ選択（三本線）

### ⑥ 主人公エナーのシート（動きの絵）
- **1536×1024**、**6列×4行**、1マス256px。絵は、中央の**224×224**。ドット：7×7px。背景はピンク。右向き。足の裏は、全部のコマで同じ高さ。
- 左上から右へ：1 立ち（目が開いている）／2 立ち（まばたき）／3 はばたき（羽を上に）／4 はばたき（羽を下に）／5 ダメージ／6 ふわり（羽を横に広げる）／7〜9 喜ぶ（立つ・ジャンプ・羽を広げる）。残りは、空きマス（ピンクのまま）。
- 32ピクセルに縮めると、キーボードの羽は「青い面が重なった形」、尾は「細い線と先の小さな四角」になります。**大きい絵のうちから、面を大きく、単純に**描いてください。

## 5. 納品

- PNG。ファイル名の例：`icon_app_1024.png`、`title_logo.png`、`title_scene.png`、`ui_buttons.png`、`ui_icons_1.png`、`hero_sheet.png`
- 直してほしい点は、こちらから、言葉で伝えます。

## 6. 受け入れの目安

- 比と大きさが、指定どおり（近くても可）。
- 角ばっていて、ぼけていない。ぼかしや光のにじみが、ない。
- 絵の中に、文字・ロゴが、ない。
- アイコンを、16pxに縮めても、何か分かる。
- エナーが、全部の絵で、同じキャラに見える（体・目・くちばし・キーボードの羽・USBの尾が、ぶれない）。
