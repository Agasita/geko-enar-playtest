# エナーとふしぎのシート　32px素材・初版

ASSET_LIST.md の 121 IDのうち 120 IDを収録。PNG 196 シート・900 コマ。J4の公開用スクリーンショットは、テーマを組み込んだゲームから撮影する工程です。

## 最初に見るもの

- preview/characters_1x_4x.png はキャラクターの原寸と最近傍4倍。
- preview/blocks_5x5.png は基本の5色。blocks_all_repeats.png は各素材を5×5に敷いた見本。
- preview/playfield_mockup.png は576×360の配置見本。実機のスクリーンショットとは別です。
- coverage.csv は仕様IDとコマ数。frames.csv はコマごとのファイル名と座標。PNGの左上が原点、単位はpx。
- atlas.json は同じ情報をIDごとに収録。9分割するコマにはnine_sliceを記載。story_motion.json は紙芝居の追加ループ素材の座標案。
- palette.json は共有32色（透明は別）。validation.json は出荷時の数値検査結果。

## Claude Codeへの引き継ぎ

既存テーマを残し、新テーマの描画にこのフォルダを使ってください。ゲーム座標や物理の値は既存実装に合わせ、描画時に論理マスと表示マスを変換します。Canvasのシート切り出しは atlas.json の file と各frameの x, y, w, h を使用。描画先を整数座標にそろえ、imageSmoothingEnabled=false。CSSでCanvasを拡大する場合はimage-rendering: pixelated。右向きが基準で、左向きはゲーム側で反転します。

A1の羽ばたき順は idle_0 → flap_up → idle_0 → flap_down。A2〜A4は独立した状態。32pxのエナーは、手前に見える翼のキーを4・3・2個の青い面として描き分けています。細かい文字は大きい絵向けです。B8のpupil名は縦、横の順で0〜2。0は上・左、1は中央、2は下・右です。C10は鍵の重ね絵と使用見本。C7の中央は透明、C8は色つきの半透明、C16は通過可能時の半透明です。

D6は色・上中下・開閉状態を組み合わせて使います。D7は一覧に列挙された茶赤青緑黄にガラスを加えた6材質。D8は横・縦・4方向の角・端の7パーツ。F2は空／入手を最大5回並べます。F17は共通背景を使う方式。W14は改ページプレビューで、工場の景色は予定素材 E18 に独立収録しています。

背景は sky → far → mid → near の順で重ねて横に反復します。必要なときだけE14の天体を空の上に1個重ねます。空以外の層は透明余白付き。UI文言・ステージ名はゲーム側で描画してください。J1のSVGはドット絵PNGを埋め込んだSVGです。

大きさは個別指定を優先し、8pxの破片、16pxの弾、24pxのかけら、48pxの顔、576×324の紙芝居などを元サイズで収録しました。外周はキャラとUIでは濃紫、連続タイルは右・下に1pxの境界を持ちます。チェックした項目は枠内座標、空コマ、可視色数、パレット外の色、景色左右端の一致です。実機での視認性・アニメの速度・当たり判定との位置合わせは未確認です。
