# ゲコ＆エナー モバイル体験版

GitHub Pagesで公開する静的ファイル一式です。ゲーム本体はgame.html内に含まれます。
ユーザーのセーブ・設定、制作資料、ステージ作成テスト用ツールは含めていません。

## 公開
1. GitHubでこの公開用のリポジトリを作成します。
2. このフォルダのファイルをリポジトリのルートへアップロードします。
3. Settings → Pages → Deploy from a branch → main / (root) を選んで保存します。
4. 発行された https://ユーザー名.github.io/リポジトリ名/ をスマホで開きます。

GitHub FreeのPagesには公開リポジトリを利用します。公開ファイル内のゲーム本体はダウンロード可能になります。
最初の起動には通信が必要です。ブラウザ用Pyxelはバージョン2.2.7の公式配信を利用します。
横持ち推奨。iPhoneはSafariの共有メニューからホーム画面に追加できます。
セーブ地点で保存した進行と言語は端末のブラウザ内に保存します。PC・他端末とは同期しません。
Safariのプライベートブラウズ等では保存されないことがあります。

## 操作
方向キーで移動。ジャンプ・攻撃・ダッシュは同時押しできます。
編集ボタンで時間停止。「マージ／範囲」を押しながら方向キーを押し、離して確定します。
シフト→実行、アンカー、カラー、戻す、手前／奥、色変更のボタンがあります。
編集を終えるボタンでアクションへ戻ります。

## 編集の新機能を試す（実験場）
URLの末尾に `?lab=1` を付けると、起動画面に「編集実験場（全スキル解放）を遊ぶ」ボタンが出ます。
実験場では、マージ・ソート・シフト・アンカー・色変更と、全モジュール（SUM・LEN・REPT・FIND・MACRO）が使えます。
編集中、そのステージでソートが使える場合は、「ソート」ボタンが出ます。押し続けながら方向キーで赤い範囲を選び、離すと確定します。
ステージ一覧（ステージ一覧ボタン）からも「EDIT LAB」を選べます。実験場の進行はセーブされません。

## 新バージョン（v2・β）
`v2/` に、ゲームを一から作り直した新バージョンがあります（起動画面の黄色いボタン、または `…/v2/` を開く）。
旧バージョン（このページ）はそのまま動くので、いつでも戻れます。設計の考え方は `docs/V2_DESIGN.md` にまとめました。
